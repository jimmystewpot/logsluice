# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| `0.1.x` | :white_check_mark: |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, report vulnerabilities privately via [GitHub Security Advisories](https://github.com/jimmystewpot/logsluice/security/advisories/new).

Include as much of the following information as possible:
- Type of issue (e.g. memory safety in SIMD kernels, denial-of-service / resource exhaustion in OTLP unpacking or cardinality tracking, on-disk codec deserialisation error).
- Affected crate (`logsluice-core`, `logsluice`, `logsluice-cli`, or `bridges/logsluice-vector`) and version/commit SHA.
- Minimal reproduction steps or proof-of-concept input.

We aim to acknowledge reports within 48 hours and provide a remediation timeline within 7 days.
